# Day 39 – Window Functions, CTEs & Recursive CTEs

## Topics Covered

* `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`
* `LAG()`
* Running totals using `SUM() OVER`
* Moving averages using `AVG() OVER`
* `NTILE()`
* `PERCENT_RANK()` and `CUME_DIST()`
* `PARTITION BY`
* Common Table Expressions (CTEs)
* Multiple CTEs
* Recursive CTEs
* Generating number and date sequences

## Practice

Practiced window functions on the `employees` table and used CTEs to filter and transform employee data. Also generated number sequences and date ranges using recursive CTEs.

## Key Learning

Window functions calculate values across related rows without grouping them into one row. CTEs make complex queries easier to organize, while recursive CTEs can generate sequences and traverse data.
